分享嵌入式学习经验，新板子测评，面试题型，帮助大家在嵌入式学习这条路上能够开拓视野

大家好，我是计算机22级实验室毕业生，也是这个仓库的发起人

为什么成立这个仓库

成立这个仓库的灵感是来自于我的一个朋友，他做了一个哈理工飞跃手册（这个手册后面我会让实验室的学生发给你们，我也负责维护工作），我也打算做这么一个手册来帮助实验室的成员快速学习嵌入式，拓宽视野，打破一些信息差，顺便也是让实验室的一些经验，传承能保留下来。
其实实验室之前也做过类似的，在库房对面的一台电脑上存放着一些实验室的资料，但是因为设计它的学长走后，我们也没有即使的维护，所以你们可能并不清楚实验室曾经也是有一个共享服务器的，实验室自成立开始资料都是代代相传，所以难免会存在部分经验，项目因为没有及时传下来而惨遭失传，所以我打算成立这个手册，尽可能的保留大家的经验，实验室的项目，并且我们也会不定期更新一些学习方法，保研面试就业的经验分享，来让实验室其他需要这方面的学生能获取经验，开拓自己的视野。
